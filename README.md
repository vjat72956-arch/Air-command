# AirCommand 🖐️💻

### Control Your Laptop with Hand Gestures

AirCommand is a Python-based touchless laptop control system that uses hand gestures and computer vision. Built with OpenCV, MediaPipe, and PyAutoGUI, it enables users to control volume, media playback, and scrolling through webcam-based hand tracking. Bringing hands-free interaction to everyday computing!

## Features

- Thumbs up: Increase volume.
- Thumbs down: Decrease volume.
- Open palm: Play or pause media.
- Index finger movement: Scroll webpages.
- Closed fist: Safety stop to disable controls.
- Real-time hand tracking through a webcam.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## How It Works

1. Webcam captures live video.
2. MediaPipe detects and tracks hand landmarks.
3. The program recognizes predefined hand gestures.
4. PyAutoGUI executes the corresponding laptop commands.

## Project Status

Currently under development. More gestures, improved accuracy, and additional laptop controls are planned.
